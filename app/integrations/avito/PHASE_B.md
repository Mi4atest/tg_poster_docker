# Авито — фаза B (чеклист)

Краткий задел после фазы A (ручная привязка, очередь, цена, архив).

## Реализовано в коде

1. **Создание объявления из поста** — `publish_post_to_avito`: при отсутствии `avito_item_id` и `can_enqueue_avito_without_linked_item()` — **автозагрузка**: XML в `media/avito_feed/current.xml`, публичный URL `https://appleshop.ap43.ru/feeds/avito.xml`, `POST /autoload/v1/upload`, ожидание `avito_id` в `/autoload/v2/reports/items`. Старый путь `POST .../items/0/` убран (405).
2. **UI при создании поста** — после шага «видео» экран «Параметры для Авито»: циклы уровней экран/корпус (0–3), сохранение в `post.avito_draft` при `POST /api/posts/`.
3. **Маппинг категории** — числовой `avito_category_id` в настройках интеграций (дерево Авито, не id ВК); опционально `avito_location_id`.
4. **Очередь без привязки** — `can_enqueue_avito_without_linked_item()`, правки в `post_management` (кнопка «в Авито», «во все», отложенная публикация, republish all).
5. **Тесты** — `tests/test_avito_phase_b.py` (черновик, цена, разбор ответа, тело запроса).
